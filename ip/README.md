# Proof of authorship / Доказательства авторства

SHA-256 digests and OpenTimestamps proofs (.ots) of dated source snapshots of Heshbon+
(app + backend + bot). The archives themselves are private; these files let anyone
verify that a snapshot with the given hash existed at the timestamped date
(verify at https://opentimestamps.org). © 2026 Heshbon+. All rights reserved.
