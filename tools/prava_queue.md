# Очередь страниц справочника /prava/ (SEO Хешбон+)

Кто пишет: задача `heshbon-seo-pages` (вс/вт/чт ~14:30) — одна страница за прогон.
Как собрать: дописать объект в `tools/prava_content.py` (PAGES) и запустить `python tools/prava_content.py` из корня репозитория. Скрипт сам пересоберёт хаб `/prava/index.html`, `sitemap.xml` и `robots.txt`.
Публикация: `git add … && git commit && git push origin main`, GitHub Pages выкатывает 1–3 минуты (проверять `curl -o /dev/null -w '%{http_code}'`).
После публикации: в Search Console (ресурс `https://heshbonplus.com/`) проверить URL и нажать «Запросить индексирование».

## Правила содержания
1. Цифры только из проверяемых источников: `rates.json` в корне репозитория (актуальные ставки), kolzchut.org.il, тексты законов на nevo.co.il, сайт Битуах Леуми. Каждую цифру сверять минимум по двум источникам; если источники расходятся — писать диапазон и оговорку, а не среднее.
2. Объём 600–900 слов, структура: h1, 4–6 разделов h2, одна таблица, блок «что проверить в тлуше», 3–5 внутренних ссылок, 4 вопроса в FAQ.
3. Никаких сторонних скриптов и трекеров: privacy.html обещает их отсутствие. Аналитика только через Search Console.
4. Тон как в наших роликах: простыми словами, без обещаний и без «мы юристы». В конце каждой страницы уже стоит дисклеймер из шаблона.
5. Ссылку на бота ставить через `https://t.me/TlushScanBot?start=seo` — это позволяет считать переходы с сайта.
